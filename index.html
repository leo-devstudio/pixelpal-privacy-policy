Pixel Pal Privacy Policy

Last updated: September 28, 2026

Pixel Pal is a remote-control and productivity application that allows users to connect the Pixel Pal mobile application to the Pixel Pal desktop application and control their desktop using customizable buttons and commands.

1. Information We Collect

Pixel Pal does not collect, store, or sell personal information.

Pixel Pal does not require users to create an account or provide personal information such as their name, email address, phone number, or physical address.

Pixel Pal does not intentionally collect contacts, photographs, messages, files, or other personal content from your device.

2. Network and Device Communication

Pixel Pal is designed to operate without cloud services or remote servers. The mobile application communicates directly with the Pixel Pal desktop application.

Information such as local network addresses or connection information may be used temporarily to establish and maintain communication between the user's mobile device and desktop computer.

This information is used solely to allow the two Pixel Pal applications to communicate and is not transmitted to or stored on our servers.

3. How Pixel Pal Uses Information

Pixel Pal uses the information necessary for device communication to:

  • Connect the mobile application to the desktop application.
  • Send commands from the mobile device to the user's desktop.
  • Maintain communication between the connected devices.
  • Provide the core functionality of the application.

Commands may include keyboard shortcuts, application launches, undo/redo commands, and controls for supported desktop applications.

4. Data Sharing

Pixel Pal does not sell, rent, or share users' personal information with third parties.

Pixel Pal does not use personal information for advertising, advertising profiles, or targeted marketing.

5. Data Storage

Pixel Pal does not operate a cloud-based account system or maintain servers that store users' personal information.

Any application settings or configurations stored by Pixel Pal are stored locally on the user's device or computer.

6. Third-Party Applications

Pixel Pal may allow users to create commands that interact with applications installed on their desktop, such as web browsers, Discord, OBS Studio, or other applications.

Pixel Pal does not control how third-party applications collect, use, or process information. Users should review the privacy policies of those applications separately.

7. Children's Privacy

Pixel Pal does not knowingly collect personal information from children. The application does not require users to provide personal information to use its core functionality.

8. Data Security

Pixel Pal is designed to communicate directly between the user's mobile device and desktop computer without relying on cloud servers for its core functionality.

Users should ensure that their local network and devices are secured appropriately. No method of electronic communication can be guaranteed to be completely secure.

9. Changes to This Privacy Policy

We may update this Privacy Policy if the functionality or data practices of Pixel Pal change. Any updated version will be published on this webpage with a revised "Last updated" date.
